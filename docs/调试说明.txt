power-hub 上位机 调试说明
============================

一、日志在哪里
  程序运行时会在自己所在文件夹下创建 logs 文件夹：
      power-hub.exe 所在目录\logs\power-hub.log
  若该位置写不进去（例如程序被放进了 Program Files），日志自动改存：
      C:\Users\<用户名>\AppData\Local\dev.powerhub.app\logs\power-hub.log

二、日志大小控制（循环覆盖，无需手动清理）
  单个日志文件最大 10MB；写满后自动滚动为 power-hub.log.old（更旧的被覆盖）。
  目录里始终最多两个文件，总量不超过 20MB。

三、如何记录更详细的信息（Debug 级，含串口原始帧收发）
  方式 1：双击同目录的 调试.bat（以详细模式启动程序）。
  方式 2：命令行启动时加参数：power-hub.exe --verbose

四、出问题时发回什么
  1. 整个 logs 文件夹（里面两个文件都发）；
  2. 现象描述：哪个通道、插了什么设备、做了什么操作、UI 提示了什么；
  3. 若程序崩溃，日志末尾的 panic 段落一并保留。

五、常见日志对照
  - "握手判据不符 / 不是 power-hub"：这个串口的对端不是本 hub，换下一个串口试。
  - "hub 应答超时"：hub 没回话。优先检查 TX/RX 是否接反、hub 是否上电、波特率是否 115200。
  - "串口错误: ..."：串口被别的程序占用，或 USB 转串口线被拔出。
  - "读通道 N 电流失败"：N 号通道的电流读取没有成功，结合上面三条排查。
