# 文本行协议 + hub 纯被动应答

串口协议同时被固件、上位机、AI 技能三方消费，需在可靠性、可调试性、AI 可解析性之间取舍。决定采用 115200bps 文本行协议，每行行尾附异或（XOR）校验；hub 为纯被动应答器——永不主动上报，一切数据由上位机轮询获取，遥测电流分辨率 0.1mA。

## Considered Options

- **二进制帧（帧头 + 长度 + CRC16）**：更紧凑严谨，但三方解析与人工调试（串口助手）成本都显著更高。115200bps 下 7 通道 × ~30B × 2Hz ≈ 0.4KB/s，带宽毫无压力，紧凑性无价值。

## Consequences

- 被动应答消除了主动上报的粘包 / 缓冲积压问题，轮询节奏与失败重试的控制权完全在上位机。
- 协议中不存在"设置上报周期"类命令；轮询间隔是上位机的内部参数。
