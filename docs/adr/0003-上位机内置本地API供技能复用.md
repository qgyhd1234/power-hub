# 上位机内置本地 API 供技能复用，技能降级直连串口

串口是独占资源：上位机打开串口期间，AI 技能无法再打开同一串口。决定：上位机内置 `127.0.0.1:8756` 的 HTTP/WebSocket 服务，对外提供遥测与电源控制，与 UI 共享同一份轮询缓存；技能优先连接本地 API，连接失败时自动降级为直连串口。

## Considered Options

- **各自独立开串口**：实现最简，但上位机运行期间技能完全不可用。
- **独立后台守护进程**：数据同源最彻底，但对单用户桌面工具过重。
- **随机 token + 发现文件鉴权**：更严谨，但引入落盘与文件分发，初版从简不做。

## Consequences

- 端口固定为 8756，被占用时上位机启动失败并提示用户，不做动态端口（技能需要稳定端口）。
- 防恶意网页跨站调用（CSRF）仅保留一道零配置防线：API 要求携带自定义请求头 `X-Power-Hub: v1`。浏览器跨站的"简单请求"无法携带自定义头，CORS 预检会将其拦下。无 token、无落盘、技能侧仅多一行 header。
- 技能经 API 获取的是上位机已轮询好的实时数据，无需自行维持轮询。
