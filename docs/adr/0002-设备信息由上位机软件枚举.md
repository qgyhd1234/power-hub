# 设备信息由上位机软件枚举，串口协议不含设备字段

需要展示每个端口所接设备的信息。决定：上位机通过 Windows USB 设备树枚举（SetupAPI 系方案）按 hub 拓扑定位各端口设备，读取 VID/PID/产品名；串口协议不携带任何设备信息字段。

## Considered Options

- **固件上报每口设备**：要求 hub 主控具备端口设备感知能力，增加固件复杂度，且通道断电后固件侧信息与"无设备"语义易冲突。
- **混合（协议预留字段 + 软件兜底）**：预留字段若固件永远不填，就是死重量。

## Consequences

- 设备信息与电源状态天然一致：通道断电 → 设备掉线 → 枚举自然消失。
- 上位机需要在 USB 树中定位"本 hub"（依据 hub 的 USB VID/PID 或端口数特征），此依赖在本仓库内实现。
