# power-hub 串口协议 v1 摘要

> 权威规范：仓库 `docs/protocol.md`。本摘要仅供快速回忆。

- 物理层：UART 115200 8N1，ASCII 文本行，行尾 CRLF，行长 ≤128 字节。
- 方向：严格一问一答，hub 永不主动发送。
- 帧格式：`<payload>*<HH>`，`HH` 为 payload 全字节 XOR（两位大写 hex）；校验失败静默丢弃。
- 数字：电压 mV 整数（`5023` = 5.023 V）；电流 0.1 mA 整数（`8421` = 842.1 mA）。

## 命令

| 命令              | 应答                                              |
| ----------------- | ------------------------------------------------- |
| `PING`            | `PONG`                                            |
| `VER?`            | `VER,<fw>,<proto>,<ch>`（proto=1，ch=7）          |
| `PWR?`            | `PWR,<sw1>,<mv1>,<c1>,…` 共 21 字段（7 通道）     |
| `SW,<ch>,ON\|OFF` | `OK`                                              |
| （出错时）        | `ERR,<1..4>,<msg>`：1 未知命令 2 参数 3 通道越界 4 内部 |

- `<swN>` ∈ {0,1}；通道关闭时 `<cN>` 恒为 0。
- 上位机应答超时 200 ms；轮询节奏自定（默认 500 ms）。
