# power-hub 串口协议速查（二进制帧）

> 权威规范：仓库 `docs/protocol.md`（协议唯一权威来源，与本摘要冲突时以它为准）。本摘要仅供快速回忆。

- 物理层：UART 115200 8N1。
- 方向模型：严格一问一答（主从式），全部由上位机发起，hub **永不主动发送**；hub 上电待命，7 通道默认全部开启。
- 数据编码：电流 = IEEE 754 float32 小端，单位 **mA**；电压不传输（上位机恒按 5.000 V 假定）；功率 = 5.000 × I(mA) / 1000。

## 帧格式（定长，无校验字段）

| 方向         | 帧长   | 结构                                  |
| ------------ | ------ | ------------------------------------- |
| 上位机 → hub | 4 字节 | `A5` + 指令(1B) + 数据(1B) + `5A`     |
| hub → 上位机 | 7 字节 | `A5` + 指令(1B) + 数据(4B) + `5A`     |

- 多字节整数一律小端。
- 帧完整性仅靠"包头 + 包尾 + 定长 + 指令白名单"过滤；非法帧（包头/包尾不对、未知指令、参数越界）hub 一律**静默丢弃不应答**，上位机以超时判定。
- 两端按定长解析：字节流中定位 `A5` 后读取定长，校验包尾与指令合法性；不合法则整帧丢弃，从下一字节重新同步。

## 命令表

| 指令 | 请求                       | 应答                                     |
| ---- | -------------------------- | ---------------------------------------- |
| 0x00 | `A5 00 00 5A`（握手）      | `A5 00 <fw> <proto> <ch> <sw> 5A`        |
| 0x01 | `A5 01 <data> 5A`（通道设置） | `A5 01 <sw> 00 00 00 5A`              |
| 0x02 | `A5 02 <ch> 5A`（读电流）  | `A5 F<ch> <float32 LE> 5A`（0xF1~0xF7）  |

- **握手判据**（打开串口确认对端是 hub）：应答为 7 字节定长帧，且指令 = `0x00`、`proto` = `0x01`、`ch` = `0x07`、包尾 = `0x5A`；`<fw>` 与 `<sw>` 取值不参与判据。任一条不满足即非 hub。握手应答顺带带回通道状态，连接成功即可同步。
- 0x01 数据字节：bit4 = 0 关 / 1 开，低 4 位 = **通道索引**（0 基：`0`=通道 1，`6`=通道 7），bit5~bit7 恒 0。例：开通道 1 = `0x10`，开通道 7 = `0x16`，关通道 7 = `0x06`；索引 ≥7 或高位置位非法、静默丢弃。应答首字节 `<sw>` 为**动作执行后**的 7 通道状态掩码（bit0~bit6 对应通道 1~7，1 = 开）。⚠ 与 0x02 基准不同！
- 0x02 请求 `<ch>` = 通道号 1~7（**1 基**，与 0x01 的 0 基索引不同）；应答指令借用通道号（`0xF1`~`0xF7`），数据 4 字节 = 电流 mA，通道关闭恒 `0.0`。示例：读通道 3 得 1024.0474 mA → `A5 F3 84 01 80 44 5A`。
- 0x00 兼作**状态查询**：会话中可周期发送（建议 3 秒），hub 无主动上报，上位机以应答掩码感知手动控制等带外变化；发生超时或重连时应重新握手。
- 无错误应答帧；上位机等待应答超时即按失败处理，必要时重试。

## 时序约束

- 应答超时：200 ms 未收到完整合法帧视为超时，可重试。
- 轮询节奏由上位机自定（默认 500 ms）；一轮全通道轮询 = 7 × `0x02`，115200 bps 下线时间约 7 ms。
- hub 无发送缓冲：收到完整合法帧立即应答。

## 串口发现

1. 枚举系统全部串口（排除蓝牙虚拟口），按 CH340 控制口魔术字（见下节）过滤，只探测 hub 控制串口；过滤无命中时回退探测全部候选口（脚本打印一行回退说明）。
2. 逐口发 `0x00` 握手，按上述判据判定。
3. 判定通过即认作 hub；超时或判据不符则关闭并探测下一个。

## 魔术字（实测值）

权威定义处：上位机 `src-tauri/src/magic.rs`（协议规范 §9）。

| 项                     | 值              | 说明                                                                                     |
| ---------------------- | --------------- | ---------------------------------------------------------------------------------------- |
| hub 主控 USB VID/PID   | `0x0451/0x8142` | 实测 TI TUSB8041 两片级联组成 1 转 7（4+4 口，级联占 1 口）：高速半 HS = `0451:8142`，SuperSpeed 半 SS = `0451:8140` 留作档案 |
| 控制串口 CH340 VID/PID | `0x1A86/0x7523` | 串口发现过滤锚点：只探测 CH340 串口，无命中回退全部候选口；CH340 系列出厂固定描述符          |
